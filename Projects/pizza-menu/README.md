# 🍕 Fast React Pizza Co.

A simple React menu app built to practice core concepts.

### 🚀 What I Learned:

- **Components:** Building reusable UI blocks.
- **Props:** Passing data from parent to child.
- **Map & Keys:** Rendering lists from data arrays.
- **Logic:** Using ternary operators and `&&` for store hours.

### 🛠️ Tech Stack:

- React.js
- JavaScript
- CSS

### 🏃 How to run:

1. `npm install`
2. `npm start`
